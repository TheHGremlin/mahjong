# Mahjong

A no-frills Mahjong solitaire in the spirit of the old Windows 3.1/95-era games, with fantasy-themed picture tiles.

- **One layout, every time** — the classic 144-tile "Turtle."
- **No power-ups.** No shuffles, no bombs. Just Hint (costs points) and Undo.
- **Readable picture tiles** — every tile is a distinct fantasy icon (sword, potion, treasure chest, d20…) instead of numbers or Chinese characters, so there's nothing to count or decode.
- **Numbered games.** Every game number always deals the same board, so you can replay one or send it to a friend (`index.html#1234`).
- **Every deal is winnable.** Boards are generated by simulating a full clear, so a solution always exists.

## How to play

Remove all tiles by clicking matching pairs. A tile can be removed only if nothing is stacked on top of it and its left or right side is open. Any Gem matches any Gem; any Shield matches any Shield.

| Action | Points |
| --- | --- |
| Remove a pair | +10 |
| Hint | −20 |
| Undo | takes back the pair's points |

Keyboard: **H** hint, **Ctrl+Z** undo, **N** new game, **M** sound on/off, **Esc** deselect.

## Running it

It's plain HTML, CSS and JavaScript with no build step. Serve the folder with any static web server, for example:

```bash
python -m http.server 8000
```

then open <http://localhost:8000>. It can also be hosted as-is on GitHub Pages.

## Installing on a phone

The game can be added to a home screen and runs like an app, including offline.

- **iPhone (Safari):** Share button → **Add to Home Screen**.
- **Android (Chrome):** ⋮ menu → **Add to Home screen** or **Install app**.

## Files

- `index.html` — page structure
- `style.css` — page and tile styling
- `tiles.js` — SVG artwork for each tile face
- `sound.js` — sound effects, synthesized with the Web Audio API
- `manifest.webmanifest`, `icon*.png`, `apple-touch-icon.png`, `icon.svg` — app name and icons for home-screen install
- `sw.js` — service worker for offline play
- `game.js` — layout, dealing, rules, scoring and UI
