# Mahjong

A no-frills Mahjong solitaire in the spirit of the old Windows Entertainment Pack games.

- **One layout, every time** — the classic 144-tile "Turtle."
- **No power-ups.** No shuffles, no bombs. Just Hint (costs points) and Undo.
- **Simple, readable tiles** — flat shapes, big numbers, distinct colors.
- **Numbered games.** Every game number always deals the same board, so you can replay one or send it to a friend (`index.html#1234`).
- **Every deal is winnable.** Boards are generated by simulating a full clear, so a solution always exists.

## How to play

Remove all tiles by clicking matching pairs. A tile can be removed only if nothing is stacked on top of it and its left or right side is open. Any Flower matches any Flower; any Season matches any Season.

| Action | Points |
| --- | --- |
| Remove a pair | +10 |
| Hint | −20 |
| Undo | takes back the pair's points |

Keyboard: **H** hint, **Ctrl+Z** undo, **N** new game, **Esc** deselect.

## Running it

It's plain HTML, CSS and JavaScript with no build step. Serve the folder with any static web server, for example:

```bash
python -m http.server 8000
```

then open <http://localhost:8000>. It can also be hosted as-is on GitHub Pages.

## Files

- `index.html` — page structure
- `style.css` — Windows 95-style chrome and tile styling
- `tiles.js` — SVG artwork for each tile face
- `game.js` — layout, dealing, rules, scoring and UI
